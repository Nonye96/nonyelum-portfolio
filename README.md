# Nonyelum Ogbuakanne — Developer Portfolio

A personal portfolio website showcasing my projects, skills, and experience as a frontend and mobile developer based in Calgary, Alberta.

## Built with

- React + TypeScript
- Vite
- Tailwind CSS

## Features

- Responsive design across desktop and mobile
- Sections for about, skills, services, projects, process, FAQ, and contact
- Downloadable resume and links to project repositories

## Running locally

1. Install dependencies:
npm install

2. Start the dev server:
npm run dev

3. Open the URL Vite prints (usually http://localhost:5173).
